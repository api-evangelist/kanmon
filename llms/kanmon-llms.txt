# Kanmon

> Kanmon is an embedded-lending platform. It lets vertical SaaS and business-management platforms offer working capital to their customers — term loans, lines of credit, invoice financing, Accounts Payable financing, and integrated merchant cash advances — through the Kanmon Public V2 REST API and the embeddable Kanmon Connect UI. Kanmon is the licensed lender and handles underwriting, compliance, and credit risk.

This llms.txt was generated by API Evangelist from the public Kanmon OpenAPI and SDK repositories. Kanmon's own documentation (kanmon.dev) is gated behind an account-manager invite.

## API

- [Kanmon Public V2 API (OpenAPI 3.0)](https://raw.githubusercontent.com/api-evangelist/kanmon/refs/heads/main/openapi/kanmon-openapi-original.yml): 35 operations across Businesses, Users, Prequalifications, Connect Tokens, Embedded Sessions, Offers, Issued Products, Invoices, Bank Accounts, Payments, Draw Requests, Documents, Integrated MCA, and Sandbox Utilities.
- Production base URL: https://api.kanmon.com
- Sandbox base URL: https://api.kanmon.dev
- Authentication: platform API key in the `Authorization` header.
- Pagination: `offset` / `limit` query parameters on collection endpoints.
- Rate limiting: `X-RateLimit-Limit` and `X-RateLimit-Remaining` headers; 429 on exceed.
- Events: outbound webhooks (e.g. USER.CREATED, BUSINESS.NEW_ACCOUNT).
